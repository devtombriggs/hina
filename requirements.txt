Build a polished, responsive physiotherapy website based on the supplied Lynch Physiotherapy & Wellness branding and logo.

The finished site should closely match the visual style of the provided concept image: clean, premium, clinical but welcoming, with lots of white space, teal branding, pale aqua section backgrounds, rounded cards, subtle shadows, and strong appointment CTAs.

IMPORTANT:
- The existing Lynch Physiotherapy & Wellness logo is already available in the project directory. Find and use that asset rather than recreating the logo in CSS/text.
- Preserve the logo proportions and do not distort it.
- Build this as a real responsive website, not a static screenshot.
- It should look excellent on desktop, tablet and mobile.
- Use semantic HTML and accessible controls.
- All navigation should work as page anchors for now.
- The “Book an Appointment” buttons should link to a configurable external booking URL.
- Keep all business details in an easy-to-edit config/data object rather than scattering them throughout components.

DESIGN DIRECTION

Overall visual style:
- Modern private healthcare / physiotherapy clinic.
- Bright, clean, calm and professional.
- White is the dominant background.
- Teal is the main brand colour.
- Very pale blue/teal backgrounds should differentiate sections.
- Dark navy/charcoal text rather than pure black.
- Use generous vertical spacing.
- Rounded rectangular cards.
- Fine borders with very subtle blue-grey tones.
- Soft box shadows only where useful.
- Avoid anything that looks overly corporate or like an NHS website.
- It should feel like a premium independent physiotherapy practice.

RESPONSIVE BEHAVIOUR

Desktop 1200px+:
- Full navigation.
- 2-column hero.
- 3-column service/testimonial grids.

Tablet 768px–1199px:
- Reduce hero heading.
- Still allow 2-column hero where space permits.
- Service grid 2 columns.
- Footer 2 columns.

Mobile under 768px:
- Hamburger nav.
- Hero stacks text above image.
- Buttons either stacked or full-width.
- Icon benefits can become vertical or 3 narrow columns if readable.
- All card grids 1 column.
- About image underneath text.
- CTA stacks.
- Footer single column or 2 compact columns.
- Ensure no horizontal overflow.
